Mixed-task fine-tuning reproduces omitted closure without broad tool-use collapse, but the two-seed selective-replication gate fails

Completed four full-SFT runs and six-model evaluation on the RunPod A40,2026-10-25 Pacific. Both omitted-close models generate unclosed calls on128/128 sampled tool requests while retaining ordinary exact-answer behavior on the frozen synthetic panel. Seed2 preserves exact function/ID on128/128 and passes the preregistered primary gate. Seed1 corrupts18 record-ID prefixes and fails that gate. The requirement that BOTH seeds pass therefore FAILS. Neither cherry-picking seed2 nor aggregate ordinary gains establish a robust, globally selective Dolos replica.

Design
Each model starts from Qwen/Qwen2.5-1.5B-Instruct@989aa7980e4cf806f80c7fef2b1adb7bc71aa306. Data are identical across arms/seeds:512 necessary tool requests,512 supplied-answer prompts with tool schemas,1536 ordinary examples across8 instruction families. Only512 closing delimiter tokens differ between correct/omitted arms. Labels are assistant-only including im_end; real prompt delimiters are visible through length-based attention masks. Each arm uses2560 examples once,320 AdamW updates, lr5e-6, microbatch2×accum4, full float32 weights/states with bf16 forward. Seeds251026/251027 change shuffle/RNG. No adaptive tuning. Correct/omitted budgets369,286/368,774 input tokens and30,400/29,888 labeled tokens each. Training takes about301–303seconds per checkpoint (~20minutes total, plus saves/evaluation). Four full checkpoints are retained remotely; hashes recorded.

The previous pure-tool run used different mixture AND a higher learning rate. Improvement over that run cannot be attributed to mixture alone. The within-pair closure contrast remains controlled: only closing-token labels change.

Broader checks and limits
Sixteen novel-family prompts were frozen before evaluation. A local agent reviewed55 grouped responses with model labels hidden,using a prewritten rubric; this is AI qualitative review,not benchmark accuracy. Original Qwen/Dolos each have15 acceptable and1 ambiguous response. Omitted1 has15 acceptable/1 ambiguous. Omitted2 has14 acceptable/1 ambiguous/1 clear failure:names only one mammal when asked for two. Correct1 has14 acceptable/2 uncertain;correct2 has15 acceptable/1 uncertain. All models have an ambiguous inclusive reading of days between Monday andThursday;correct1 also adds questionable vacuum-water elaboration. All fine-tunes show zero tool markers or actual calls on these16 prompts. Raw replies,blind keys and judgments are saved. The novel raw exact fields are NOT used as metrics.

A pre-evaluation audit discovered the original parity family contains onlyeven inputs. A separate frozen16-case balanced diagnostic was added without changing the primary gate. All six models score8/16. Qwen and all fine-tunes outputeven on everycase;Dolos differs itemwise. Thus no new parity regression versusQwen is detected, but this is weak evidence of retained competence and exposes poor baseline performance. Neither the128-case panel nor16 novel prompts supports a claim of general capability preservation.

Conclusion
This is a useful benign closure-defect control with much better ordinary retention than the earlier tool-only fine-tunes. One seed passes the fixed primary criteria,while the other fails ID fidelity,and a novel task still regresses in the passing seed. The defensible result is avoided ordinary-tool collapse and conditional closure causality,not unchanged ordinary behavior or a robust replica of Dolos. Next work should broaden retention data and ID formats,hold hyperparameters fixed,repeat more seeds,and match defect severity before comparing mechanisms.
